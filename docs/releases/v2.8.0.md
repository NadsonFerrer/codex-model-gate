# Codex Model Gate 2.8.0

A seleção automática agora analisa a tarefa, o conteúdo dos anexos e o catálogo completo de skills com IA. As competências escolhidas e suas justificativas aparecem antes da autorização da execução.

- Memória incremental com descrições completas e escopo de cada skill; novas competências podem ser selecionadas sem cadastrar rotas temáticas.
- Prévia de texto, DOCX, PDF com texto e XLSX, entrada visual de imagens e indicação das limitações de leitura.
- Análise em segundo plano pelo CLI autenticado, sandbox somente leitura e cancelamento; a análise consome tokens.
- Correção do perfil YAML da orquestradora interna, atualização para V12 e preservação de personalizações.
- Identificação da versão do CLI, acesso à atualização oficial e Sol 6.1 como modelo Sol principal.
- Melhorias de interface, persistência, pacotes de tarefas, backups, histórico, consumo e cancelamento de processos.

Validação local: **107 testes passaram**, incluindo interface Tk, backup, migração e seleção inteligente. Três avaliações reais pelo CLI verificaram seleção para consulta factual, conteúdo contratual e imagem de cartão empresarial. Esses casos não garantem escolhas perfeitas em toda tarefa; revise as recomendações antes de autorizar.

## Downloads

- **CodexModelGate-Setup.exe**: instalador para Windows 10/11 x64, com atalhos e desinstalador.
- **CodexModelGate-Pendrive.exe**: executável portátil direto.
- **SHA256SUMS.txt**: hashes dos binários desta distribuição.
- **LEIA-ME-PORTATIL.md**: instruções da edição portátil.

Os executáveis incluem Python e as bibliotecas do aplicativo. A análise inteligente e a execução exigem Codex CLI compatível e autenticado; a seleção inteligente usa Sol 6.1, que exige CLI 0.159.1 ou posterior. Acesso ao modelo depende da conta.

A atualização padrão preserva os dados locais. Um perfil novo inicia com tarefa vazia; um perfil existente pode recuperar seu próprio rascunho ou conversa pendente. A biblioteca de skills é a de cada usuário; skills, tarefas e configurações pessoais não são distribuídas com os instaladores.
