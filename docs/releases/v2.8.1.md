# Codex Model Gate 2.8.1

This release makes the controlled browser available automatically when a task asks for current web research, includes a URL, or asks the Gate to access a website. The browser can open HTTP/HTTPS pages directly, follow links from the page, and read text in embedded frames. Browser diagnostics are added to the task record so a browser-tool failure is not mistaken for proof that a website is unavailable.

- Starts the bundled browser MCP server as a required task-scoped tool when enabled, and restores the executable environment needed by packaged Windows builds.
- Adds direct URL navigation, link following, iframe text, and structured network diagnostics while avoiding sensitive query strings in diagnostic logs.
- Requires a functional Tcl/Tk runtime before packaging so a broken graphical executable is not produced silently.
- Updates the English, Brazilian Portuguese, and Spanish manuals.

Validation: **114 automated tests passed** locally, including nine GUI regression tests and browser navigation/diagnostic tests. The packaged browser MCP was also checked against the NanoMaPE website: initialization and tool listing, home/product/detail navigation, HTTP 200 responses, and embedded-frame text all passed. A clean-machine installer test and a real model/CLI task were not run; model access still depends on the user's Codex CLI, account, and workspace.
